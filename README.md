# zevs-task-sheet-bot

Телеграм-бот на связке с Google Таблицей вместо KeyCRM (в KeyCRM нет API/вебхука для задач - проверено по полному списку методов их API).

## Как это работает

Задачи ведутся в Google Таблице (шаблон - файл шаблон_задачи.xlsx, загрузи его в Google Диск и открой как Google Таблицу). Бот раз в 20 секунд смотрит лист «Задачи»: если появилась новая строка с названием задачи - шлёт исполнителю личное сообщение с кнопкой «Взял в работу». После нажатия статус меняется на «В работе» и появляются кнопки «Выполнено» / «Не выполнено». Всё это одновременно пишется в таблицу - и текст задачи, и статус, и время каждого шага.

## Настройка Google (один раз)

1. Зайти на console.cloud.google.com, создать проект (или взять существующий).
2. В нём включить Google Sheets API (APIs & Services -> Enable APIs -> найти Google Sheets API).
3. Создать сервисный аккаунт (APIs & Services -> Credentials -> Create credentials -> Service account), у него будет свой email вида имя@проект.iam.gserviceaccount.com.
4. Создать для него ключ в формате JSON (вкладка Keys у сервисного аккаунта -> Add key -> JSON) - скачается файл.
5. Загрузить шаблон_задачи.xlsx в Google Диск, открыть как Google Таблицу.
6. В настройках доступа таблицы дать этому email сервисного аккаунта доступ Редактора.
7. Скопировать ID таблицы - это часть ссылки между /d/ и /edit: docs.google.com/spreadsheets/d/ЭТОТ_ID/edit.

## Переменные окружения на Railway

- `TELEGRAM_BOT_TOKEN` - токен бота от @BotFather
- `SPREADSHEET_ID` - ID таблицы из шага 7
- `GOOGLE_SERVICE_ACCOUNT_JSON_B64` - содержимое скачанного JSON-ключа, закодированное в base64 одной строкой (команда ниже)
- `POLL_INTERVAL_SECONDS` - необязательно, по умолчанию 20

Закодировать ключ в base64 (в терминале, там же где лежит скачанный файл):

```
base64 -w0 service_account.json
```

на Windows (PowerShell):

```
[Convert]::ToBase64String([IO.File]::ReadAllBytes("service_account.json"))
```

Результат целиком вставить в переменную `GOOGLE_SERVICE_ACCOUNT_JSON_B64`.

## Деплой на Railway

Подключить репозиторий, добавить переменные окружения выше, Railway подхватит Procfile сам. Сервис не открывает никакой веб-адрес (это фоновый процесс, не сайт) - настройки healthcheck в Railway трогать не нужно, можно оставить по умолчанию.

## Как пользоваться

1. На листе «Сотрудники» вписать имя каждого и его chat_id (сотрудник получает свой chat_id, написав боту /start).
2. На листе «Задачи» заполнить Задача / Постановщик / Исполнитель / Срок выполнения - остальное бот проставит сам.
3. Имя в «Исполнитель» должно быть написано точно так же, как на листе «Сотрудники».

## Ограничения

- Бот проверяет таблицу раз в POLL_INTERVAL_SECONDS (по умолчанию 20 сек) - уведомление приходит не мгновенно, а с этой задержкой.
- Если два человека одновременно правят одну и ту же ячейку в Таблице руками - возможен конфликт версий, это ограничение самого Google Sheets, не бота.
